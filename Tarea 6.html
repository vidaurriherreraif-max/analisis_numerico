Ejercicio 1

La Ley de Enfriamiento de Newton establece que la tasa de enfriamiento de un objeto es proporcional a la diferencia de temperatura entre el objeto y su entorno. Supongamos que \(t\) es el tiempo, \(T\) es la temperatura del objeto, y \(T_s\) es la temperatura del entorno. La ecuación diferencial que describe la Ley de Newton es:

\[\frac{dT}{dt} = k(T - T_s)\]

Consideramos una taza de café a 95 °C en una habitación de 18 °C. Se sabe que el café se enfría a una razón de 2 °C/min cuando su temperatura es de 70 °C.

Cálculo de \(k\):

En el momento en que \(T = 70\) °C se tiene \(\frac{dT}{dt} = -2\) °C/min (negativo porque el café se enfría), por lo que:

\[-2 = k(70 - 18) \implies k = \frac{-2}{52} \approx -0.03846 \text{ min}^{-1}\]

La solución analítica de la EDO con \(T(0) = 95\) °C es:

\[T(t) = T_s + (T_0 - T_s)\,e^{kt} = 18 + 77\,e^{kt}\]

Código 
# Parámetros del problema
T0 = 95      # temperatura inicial del café (°C)
Ts = 18      # temperatura de la habitación (°C)
k  = -2 / (70 - 18)   # constante de enfriamiento

print(f"k = {k:.6f} min⁻¹")

# Función que define la EDO
def f_newton(t, T):
    return k * (T - Ts)

# Intervalo de tiempo y condición inicial
t0 = 0
tf = 120   # 2 horas
s0 = [T0]
t_values = np.linspace(t0, tf, 500)

# Solución numérica
edo_sol = integrate.solve_ivp(f_newton, [t0, tf], s0, t_eval=t_values)

# Solución analítica para comparación
T_analitica = Ts + (T0 - Ts) * np.exp(k * t_values)

# Gráfica
plt.figure(figsize=(8, 5))
plt.plot(edo_sol.t, edo_sol.y[0], color='darkred', label='Solución numérica $T(t)$')
plt.plot(t_values, T_analitica, color='steelblue', linestyle='--', label='Solución analítica')
plt.axhline(Ts, color='black', lw=1, ls='--', label=f'$T_s = {Ts}$ °C')
plt.xlabel('Tiempo (min)')
plt.ylabel('Temperatura (°C)')
plt.title('Ley de Enfriamiento de Newton')
plt.legend()
plt.grid()
plt.show()
k = -0.038462 min⁻¹

Ejercicio 3

Para la ecuación diferencial ordinaria de segundo orden:

\[u'' - 3u' - 1.5u = 8\sin(3t), \qquad u(1) = -0.5,\; u'(1) = 1\]

Haciendo \(v = u'(t)\), el sistema de primer orden equivalente es:

\[\begin{eqnarray} u' &=& v \\ v' &=& 3v + 1.5u + 8\sin(3t) \end{eqnarray}\]

con \(u(1) = -0.5\) y \(v(1) = 1\).

Código 
def f_ej3(t, U):
    u, v = U
    return [v, 8*np.sin(3*t) + 3*v + 1.5*u]

t0 = 1
tf = 3
s0 = [-0.5, 1]
t_values = np.linspace(t0, tf, 200)

edo_sol = integrate.solve_ivp(f_ej3, [t0, tf], s0, t_eval=t_values)

plt.figure(figsize=(8, 5))

Ejercicio 10

Circuito RLC

\[LQ'' + RQ' + \frac{1}{C}Q = V(t), \qquad Q(0) = 0,\; Q'(0) = 0,\quad V(t) = \sin(t)\]

con \(L = 0.5\), \(R = 2\), \(C = 5\).

Considerando la derivada de la carga \(Q\) como la corriente \(I = Q'\), el sistema de primer orden es:

\[\begin{eqnarray} Q' &=& I \\ I' &=& \frac{1}{L}\left(\sin(t) - RI - \frac{1}{C}Q\right) \end{eqnarray}\]

Código 
def f_ej10(t, Q, L, R, C):
    q, i = Q
    return [i, (1/L)*(np.sin(t) - R*i - q/C)]

L = 0.5
R = 2
C = 5

t0 = 0
tf = 20
s0 = [0, 0]
t_values = np.linspace(t0, tf, 1000)

edo_sol = integrate.solve_ivp(f_ej10, [t0, tf], s0, t_eval=t_values, args=(L, R, C))

plt.figure(figsize=(8, 5))
plt.plot(edo_sol.t, edo_sol.y[0], label='Q(t)')
plt.plot(edo_sol.t, edo_sol.y[1], label='I(t)')
plt.xlabel('t')
plt.ylabel('Q / I')
plt.title("Circuito RLC: $LQ'' + RQ' + Q/C = \\sin(t)$")
plt.legend()
plt.grid()
plt.show()
